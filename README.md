# Tpmp_lab_7

## Overview

Source files for iOS projects on Objective-C and Swift.

## Usage

Use `Xcode` to build each project.

## Building

Open Xcode and run the project (Cmd+R).

## Repository structure

Branch `main` — file README.
Branch `feature1` — mobile app source code (all 4 tasks).

## Tasks

- **Task 1** — Drawing app on Objective-C
- **Task 2** — Gesture recognition app on Swift
- **Task 3** — Core Graphics shapes on Swift
- **Task 4** — Animation app on Swift with Russian and Chinese localization

## Additional Notes

The repository contains Swift and Objective-C source files for iOS (UIKit).
